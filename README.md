# Rudra Rajaramwala — Video Editor Portfolio

A responsive, cinematic-dark portfolio starter built with plain HTML and CSS.

## Files
- `index.html` — page content and sections
- `style.css` — responsive styling
- `images/` — add your portrait or visual assets here
- `thumbnails/` — add project cover images here

## Before publishing
1. Replace `YOUR_EMAIL@example.com` with your real contact email.
2. Replace the Instagram `#` link with your profile URL.
3. Replace each project placeholder with a real thumbnail and a working video link.
4. Do not present the category placeholders as completed client work.
5. Check the site on mobile before sharing it with clients.

## Run on Android
Open `index.html` in Acode or another HTML editor, then preview it in Chrome.

## Publish free with GitHub Pages
1. Create a public GitHub repository named `rudra-portfolio`.
2. Upload `index.html`, `style.css`, `images/` and `thumbnails/` to the repository root.
3. In the repository, open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.
6. Your site will appear at `https://rudra2662.github.io/rudra-portfolio/` after GitHub finishes deploying.

## Visual system
- Background: `#080808`
- Text: `#FFFFFF`
- Accent: `#FF6B35`
- Secondary surface: `#111111`
- Fonts: Space Grotesk (headings), DM Sans (body)
